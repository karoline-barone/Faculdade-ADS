# 🎓 Faculdade - Análise e Desenvolvimento de Sistemas (ADS)

Repositório dedicado ao armazenamento de exercícios, projetos e estudos desenvolvidos durante a graduação em Análise e Desenvolvimento de Sistemas.

## 📁 Matérias e Conteúdos
* **Linguagem C:** Exercícios, lógica e algoritmos desenvolvidos durante o 1º e 2º semestre.
* **HTML CSS:** Exercícios práticos da matéria de Desenvolvimento Web do 2º Semestre.
* **JAVA WEB:** Laboratórios e códigos de integração Web com Java do 2º Semestre.
