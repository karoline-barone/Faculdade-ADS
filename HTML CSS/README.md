# 🌐 Desenvolvimento Web - 2º Semestre (FATEC)

Este diretório é dedicado ao armazenamento e organização de todos os exercícios práticos desenvolvidos na disciplina de **Desenvolvimento Web** durante o segundo semestre da faculdade.

## 🚀 Tecnologias e Conceitos Estudados
* **HTML5:** Estruturação semântica de páginas, inserção de mídias, hiperlinks e mapas de navegação.
* **CSS3:** Estilização externa e interna, manipulação de cores, fontes, alinhamentos, bordas e criação de layouts.
* **Componentização de Telas:** Uso de estruturas modulares (como frames e páginas integradas) para a composição de interfaces.

---

## 📁 Organização dos Exercícios

Os arquivos foram divididos sequencialmente para acompanhar a evolução do aprendizado em sala de aula:

### 🔹 Fundamentos Básicos e Evolução (`ex01.html` ao `ex25.html`)
* **Exercícios Iniciais (01 ao 10):** Primeiros contatos com tags de texto, títulos, parágrafos, listas ordenadas/não ordenadas e inclusão de imagens estruturadas.
* **Exercícios Intermediários (11 ao 20):** Manipulação de formulários, tabelas de dados complexas, estilização com classes/IDs em CSS e arquivos de estilo externos como o `curriculo.css`.
* **Exercícios Avançados (21 ao 25):** Aplicação de propriedades visuais mais robustas, layouts avançados e integração fina entre o HTML e CSS moderno.

### 🔹 Estrutura e Composição de Interface (Layout Integrado)
Uma parte do aprendizado foi focada em entender como dividir e organizar partes de um site em arquivos independentes:
* `banner.html`: Cabeçalho visual e identidade do site.
* `menu.html`: Barra lateral de navegação com hiperlinks direcionados.
* `principal.html`: Área central focada na exibição de conteúdos dinâmicos.
* `frame1.html`, `frame2.html` e `frame3.html`: Exercícios específicos para o estudo de janelas, quadros de carregamento e blocos de divisão de tela.
